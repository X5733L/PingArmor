**PingArmor** — легкая и эффективная фоновая утилита для Windows, которая держит основной интернет-канал на первом месте по приоритету, устраняет скачки пинга в Wi-Fi и защищает систему от перехвата маршрутов VPN-клиентами и утечек DNS.

## 💡 Зачем нужен PingArmor?

Если вы регулярно используете VPN-клиенты (WireGuard, OpenVPN, Fortinet, Sing-box, Tailscale, v2ray) или работаете и играете через Wi-Fi, то наверняка сталкивались с типичными проблемами Windows:

1. **Перехват маршрутов VPN**: многие клиенты принудительно занижают метрику своего интерфейса до `1`. Из-за этого весь локальный и интернет-трафик уходит в туннель, отваливаются IDE (Antigravity, VS Code, JetBrains), перестают открываться локальные веб-серверы и зависают Electron-приложения.
2. **Скачки пинга и лаги в Wi-Fi**: каждые 60 секунд служба Windows выполняет фоновое сканирование эфира в поисках соседних сетей. Во время онлайн-игр (CS2, Valorant, Apex) или голосовых звонков (Discord, Zoom, Teams) это приводит к резким микрофризам с задержкой 100–300 мс.
3. **Задержки и утечки DNS**: механизм Windows Smart Multi-Homed Name Resolution опрашивает все сетевые интерфейсы параллельно, что вызывает таймауты запросов и непредвиденные утечки DNS.

**PingArmor устраняет эти проблемы автоматически, тихо и без нагрузки на систему.**

## ✨ Основные возможности

- ⚡ **Умный контроль приоритета сети**:
  - Распознает физические порты Ethernet и адаптеры Wi-Fi с подтвержденным выходом в интернет (через NCSI).
  - Назначает **метрику 5** проводному подключению (высший приоритет) и **метрику 10** для Wi-Fi.
  - Автоматически понижает виртуальные адаптеры (VPN, TAP, Wintun, Hyper-V) до **метрики 500**, если они пытаются перебить основной интернет.
- 📶 **Отключение фонового поиска Wi-Fi (защита от лагов)**:
  - Использует нативный Win32 WLAN API (`wlanapi.dll` OpCode 2 и 3), отключая периодический фоновый поиск сетей и активируя потоковый медиа-режим.
  - **Без разрывов и сброса соединения** — текущее подключение к роутеру работает стабильно, пинг выравнивается.
  - *Smart Connect-First*: утилита ждет фактического подключения к Wi-Fi перед блокировкой сканирования, поэтому при включении ПК сеть находится как обычно.
- 🔒 **Защита DNS и отключение WPAD**:
  - Включает политику `DisableSmartNameResolution = 1` в реестре, предотвращая задержки и утечки параллельного опроса DNS.
  - Отключает медленный автопоиск прокси-серверов WPAD.
  - Мгновенно очищает кэш DNS через вызов `DnsFlushResolverCache` без раздражающих всплывающих черных окон командной строки.
- 🪶 **Незаметная работа в системном трее**:
  - Иконка щита возле часов с наглядным статусом (🟢 Защищено, 🟡 Корректировка, 🔴 Нет сети, ⚪ Приостановлено).
  - Работает по системным событиям (`NetworkChange.NetworkAddressChanged`) с фильтром дебаунса 750 мс — **0.0% CPU и около 15 МБ ОЗУ**.
- 🚀 **Бесшумный автозапуск без окон UAC**:
  - Встроенный установщик регистрирует задачу в Планировщике Windows (`Task Scheduler`) с наивысшими правами, запуская утилиту при входе в систему без назойливых запросов контроля учетных записей.
- 🌐 **Встроенная мультиязычность**:
  - Полная поддержка интерфейса и CLI на английском, русском и казахском языках с мгновенным переключением.

## 🚀 Быстрый старт

### 1. Скачивание готовой сборки
Загрузите последнюю готовую версию из раздела **[GitHub Releases](../../releases)**:
- **`PingArmor-v*-win-x64.zip`**: Полностью автономная версия (~50 МБ). Все компоненты .NET 10 встроены в один исполняемый файл. Работает на любой Windows 10/11 без установки среды .NET и SDK.

Просто распакуйте архив и запустите `PingArmor.exe`!

### 2. Запуск напрямую из исходников
Если на компьютере установлен [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0):
```powershell
# Клонирование и мгновенный запуск
git clone https://github.com/X5733L/PingArmor.git
cd PingArmor
dotnet run --project src/PingArmor.csproj
```

### 3. Локальная сборка в один исполняемый файл
Для компиляции автономного `.exe` файла на вашей машине:
```powershell
dotnet publish src/PingArmor.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o ./dist/publish
.\dist\publish\PingArmor.exe
```

## 💻 Команды консоли (CLI)

PingArmor можно использовать в консоли и скриптах автоматизации:

```powershell
# Запуск в фоновом режиме (трей)
PingArmor.exe

# Просмотр сетевых адаптеров, их типов и метрик
PingArmor.exe --status

# Разовая оптимизация метрик и DNS
PingArmor.exe --optimize

# Включение / выключение подавления фонового поиска Wi-Fi
PingArmor.exe --gaming-on
PingArmor.exe --gaming-off

# Регистрация / удаление автозапуска в Планировщике Windows
PingArmor.exe --install-startup
PingArmor.exe --uninstall-startup

# Выбор языка интерфейса и вывода
PingArmor.exe --lang ru    # Русский
PingArmor.exe --lang en    # English
PingArmor.exe --lang kk    # Қазақша
```

## ⚙️ Конфигурация (`config.json`)

При старте программа создает файл `config.json` рядом с исполняемым файлом:

```json
{
  "CheckIntervalSeconds": 10,
  "PrimaryEthernetMetric": 5,
  "PrimaryWifiMetric": 10,
  "VirtualAdapterMetric": 500,
  "DisconnectedAdapterMetric": 100,
  "DisableSmartNameResolution": true,
  "DisableWpad": true,
  "FlushDnsOnChange": true,
  "ShowNotifications": true,
  "DisableIPv6OnWifi": true,
  "EnableWlanOptimizer": true,
  "Language": "ru",
  "ExcludeAdapters": []
}
```

### Назначение параметров:
- `CheckIntervalSeconds`: интервал проверки (сек) для отслеживания фоновых изменений сторонними программами.
- `PrimaryEthernetMetric`: метрика для активного Ethernet (по умолчанию `5`).
- `PrimaryWifiMetric`: метрика для активного Wi-Fi (по умолчанию `10`).
- `VirtualAdapterMetric`: метрика для VPN / виртуальных адаптеров (по умолчанию `500`).
- `DisconnectedAdapterMetric`: метрика для физических портов без кабеля (по умолчанию `100`).
- `EnableWlanOptimizer`: блокировка фонового сканирования сетей Wi-Fi (по умолчанию `true`).
- `ExcludeAdapters`: список исключений (адаптеры, которые не нужно трогать).
