## 💡 Неліктен PingArmor қажет?

Егер сіз VPN клиенттерін (WireGuard, OpenVPN, Fortinet, Sing-box, Tailscale, v2ray) жиі қолдансаңыз немесе Wi-Fi арқылы ойнап, қашықтан жұмыс істесеңіз, мынадай қиындықтарға жиі тап боласыз:

1. **VPN маршруттарын тартып алу**: көптеген VPN бағдарламалары өз интерфейсінің метрикасын күштеп `1`-ге түсіреді. Соның салдарынан бүкіл жергілікті және интернет трафик туннельге бағытталып, IDE орталары (Antigravity, VS Code, JetBrains) ажырайды, локальді серверлер қолжетімсіз болады және Electron қолданбалары қатып қалады.
2. **Wi-Fi пингінің секіруі мен джиттер**: әр 60 секунд сайын Windows жүйесі жақын маңдағы желілерді іздеу үшін фонда сканерлеу жүргізеді. Бұл онлайн ойындарда (CS2, Valorant, Apex) немесе дауыстық қоңырауларда (Discord, Zoom, Teams) кенеттен 100–300 мс микрофриздерге әкеледі.
3. **DNS кідірістері мен қауіпсіздік мәселелері**: Windows Smart Multi-Homed Name Resolution тетігі барлық желілік интерфейстерге қатар сұраныс жіберіп, жауап күту уақытын арттырады және DNS мәліметтерінің ағып кетуіне әкеледі.

**PingArmor осы мәселелердің барлығын фонда, үнсіз әрі жүйеге жүктеме түсірмей автоматты түрде шешеді.**

## ✨ Негізгі мүмкіндіктер

- ⚡ **Желі басымдығын ақылды басқару**:
  - Интернет байланысы расталған нақты физикалық Ethernet және Wi-Fi адаптерлерін автоматты түрде таниды (NCSI арқылы).
  - Сымды Ethernet байланысына **5 метрикасын** (ең жоғары басымдық), ал Wi-Fi-ға **10 метрикасын** тағайындайды.
  - Егер виртуалды адаптерлер (VPN, TAP, Wintun, Hyper-V) негізгі байланыстың басымдығын басып алуға тырысса, оларды автоматты түрде **500 метрикасына** түсіреді.
- 📶 **Wi-Fi желілерін фонда іздеуді өшіру (лагқа қарсы қорғаныс)**:
  - Нативті Win32 WLAN API (`wlanapi.dll` OpCode 2 және 3) арқылы фондағы іздеуді өшіріп, медиа-ағындық режимді қосады.
  - **Байланыс үзілмейді және қайта қосылмайды** — роутерге қосылым тұрақты жұмыс істей береді, пинг тегістеледі.
  - *Smart Connect-First*: утилита сканерлеуді бұғаттамас бұрын алдымен Wi-Fi желісіне қосылуды күтеді, сондықтан компьютер қосылғанда желі қалыпты түрде табылады.
- 🔒 **DNS қорғау және WPAD өшіру**:
  - Реестрде `DisableSmartNameResolution = 1` параметрін белсендіріп, DNS сұраныстарының кешігуін болдырмайды.
  - WPAD прокси-серверлерді баяу автоматты іздеуін өшіреді.
  - Жүйелік DNS кэшін нативті `DnsFlushResolverCache` шақыруы арқылы экранда қара консоль терезелерін көрсетпей лезде тазартады.
- 🪶 **Жүйелік трейде үнсіз жұмыс істеу**:
  - Сағат жанындағы қалқан белгішесі күйді анық көрсетеді (🟢 Қорғалған, 🟡 Реттелуде, 🔴 Қосылым жоқ, ⚪ Кідіртілген).
  - Жүйелік оқиғалар бойынша жұмыс істейді (`NetworkChange.NetworkAddressChanged`) және 750 мс дебаунс сүзгісі бар — **0.0% CPU және шамамен 15 МБ жедел жад**.
- 🚀 **UAC сұрауынсыз үнсіз автоіске қосу**:
  - Кірістірілген орнатқыш Windows Тапсырмалар жоспарлағышына (`Task Scheduler`) жоғары құқықпен тапсырма тіркейді, сондықтан қолданба жүйеге кіргенде ешқандай UAC терезесін шығармай қосылады.
- 🌐 **Көптілді интерфейс**:
  - Ағылшын, орыс және қазақ тілдерінде толық интерфейс пен CLI қолдауы, лезде тіл ауыстыру мүмкіндігі.

## 🚀 Жылдам бастау

### 1. Дайын нұсқаны жүктеп алу
Соңғы нұсқаны **[GitHub Releases](../../releases)** бөлімінен жүктеп алыңыз:
- **`PingArmor-v*-win-x64.zip`**: Толық дербес орындалатын нұсқа (~50 МБ). Барлық .NET 10 компоненттері бір файлдың ішіне енгізілген. Ешқандай қосымша .NET ортасы немесе SDK орнатпай-ақ кез келген Windows 10/11 жүйесінде бірден іске қосылады.

ZIP архивті ашып, `PingArmor.exe` файлын іске қосыңыз!

### 2. Бастапқы кодтан тікелей іске қосу
Егер компьютерде [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) орнатылған болса:
```powershell
# Көшіріп алу және дереу іске қосу
git clone https://github.com/X5733L/PingArmor.git
cd PingArmor
dotnet run --project src/PingArmor.csproj
```

### 3. Компьютерде бір файлға жинақтау
Өз компьютеріңізде дербес орындалатын файлды жинақтау үшін:
```powershell
dotnet publish src/PingArmor.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o ./dist/publish
.\dist\publish\PingArmor.exe
```

## 💻 Консольдік командалар (CLI)

PingArmor қолданбасын скрипттер мен консольде автоматтандыру үшін пайдалануға болады:

```powershell
# Фондық режимде іске қосу (трей)
PingArmor.exe

# Адаптерлерді, олардың түрін және метрикаларын көру
PingArmor.exe --status

# Метрикалар мен DNS-ті бір рет оңтайландыру
PingArmor.exe --optimize

# Wi-Fi желілерін фонда іздеуді өшіру / қосу
PingArmor.exe --gaming-on
PingArmor.exe --gaming-off

# Тапсырмалар жоспарлағышында автоіске қосуды тіркеу / өшіру
PingArmor.exe --install-startup
PingArmor.exe --uninstall-startup

# Қолданба тілін таңдау
PingArmor.exe --lang kk    # Қазақша
PingArmor.exe --lang en    # English
PingArmor.exe --lang ru    # Русский
```

## ⚙️ Баптаулар (`config.json`)

Іске қосылғанда бағдарлама орындалатын файл жанынан автоматты түрде `config.json` файлын жасайды:

```json
{
  "CheckIntervalSeconds": 10,
  "PrimaryEthernetMetric": 5,
  "PrimaryWifiMetric": 10,
  "VirtualAdapterMetric": 500,
  "DisconnectedAdapterMetric": 100,
  "DisableSmartNameResolution": true,
  "DisableWpad": true,
  "FlushDnsOnChange": true,
  "ShowNotifications": true,
  "DisableIPv6OnWifi": true,
  "EnableWlanOptimizer": true,
  "Language": "kk",
  "ExcludeAdapters": []
}
```

### Параметрлер сипаттамасы:
- `CheckIntervalSeconds`: бөгде бағдарламалардың өзгерістерін қадағалау уақыты (секунд).
- `PrimaryEthernetMetric`: белсенді Ethernet метрикасы (әдепкі: `5`).
- `PrimaryWifiMetric`: белсенді Wi-Fi метрикасы (әдепкі: `10`).
- `VirtualAdapterMetric`: VPN және виртуалды адаптерлер метрикасы (әдепкі: `500`).
- `DisconnectedAdapterMetric`: кабель ажыратылған физикалық порттар метрикасы (әдепкі: `100`).
- `EnableWlanOptimizer`: Wi-Fi желілерін фонда іздеуді бұғаттау (әдепкі: `true`).
- `ExcludeAdapters`: оңтайландыру кезінде ескерілмейтін адаптерлер тізімі.
